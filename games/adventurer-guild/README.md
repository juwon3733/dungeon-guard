# 모험가 길드 (시험판)

길드장이 되어 모험가를 모으고, 던전에 파견하는 수집형 게임입니다. `index.html`을 더블클릭하면 설치 없이 실행됩니다. 기록은 브라우저 저장소(`adventurerGuild.save.v1`)에 남습니다.

## 지금 되는 것
- **모집**: 1회, 10회. 10번째는 SR 이상, 60번째는 SSR 확정입니다. 같은 모험가가 또 나오면 ★이 오르고(최대 ★5), 그 뒤로는 금화가 됩니다.
- **도감**: 검색, 등급·직업·보유 필터, 정렬. 모험가가 수백 명으로 늘어도 같은 모양의 격자로 늘어납니다.
- **캐릭터 상세**: 레벨업, 특기 태그, 소개와 ★3에서 열리는 숨은 이야기, 인연 목록.
- **파견**: 던전 4곳, 파티 1~4명, 실제 시간이 흐릅니다(꺼 두어도 진행). 던전이 요구하는 특기 태그를 파티가 많이 덮을수록 성공률이 오릅니다.
- **인연**: 같은 파티의 친구(성공률 +6%)와 앙숙(-4%)이 파견 보고서에 대사를 남깁니다.
- 출석 보상(하루 한 번).

## 구조
```
index.html, style.css
js/data.js   캐릭터, 인연, 던전 표 (여기에 한 줄 더하면 캐릭터가 늘어납니다)
js/game.js   규칙(뽑기, 성장, 파견). 화면과 분리되어 Node에서 시험할 수 있습니다
js/ui.js     화면
assets/characters/<id>/card.png, icon.png   그림 (없으면 임시 카드)
docs/ART_SPEC.md   그림 담당용 규격과 캐릭터 목록
```

수치(확률, 전투력, 보상)는 모두 초안입니다.
