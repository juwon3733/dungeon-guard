# 캐릭터 그림 규격 (그림 담당용)

캐릭터 한 명당 **그림 2장**이면 게임에 들어갑니다. 파일만 넣으면 되고 코드는 건드리지 않습니다.

```
assets/characters/<id>/card.png   전신 또는 반신 일러스트 (상세 화면, 큰 카드)
assets/characters/<id>/icon.png   얼굴이 보이는 정사각형 가까운 썸네일 (도감, 파티, 모집 결과)
```

`<id>`는 `js/data.js`의 `CHARACTERS`에 있는 영문 id입니다(예: `seraphine`, `nyx`). 파일이 없는 캐릭터는 임시 카드(직업 기호)로 나옵니다.

## 크기와 형식

| 파일 | 비율 | 권장 크기 | 비고 |
|---|---|---|---|
| card.png | 3:4 세로 | 900 x 1200 | 배경은 단색 또는 그라데이션 어느 쪽이든 됩니다. 투명 배경도 가능합니다 |
| icon.png | 3:4 세로 | 300 x 400 | 얼굴이 위쪽 가운데에 오게 그려 주세요 |

- PNG, 파일당 1MB 이하를 권합니다(수백 장이 되어도 가볍게 열리게).
- 도감 칸은 `object-fit: cover`로 잘립니다. 아래쪽 20%는 이름 띠에 가려지고, 위쪽 모서리에 등급과 레벨 글자가 얹힙니다. 얼굴과 중요한 소품은 **가운데 위쪽 60%** 안에 두세요.
- 등급 테두리(N 회색, R 파랑, SR 보라, SSR 금색)는 게임이 그립니다. 그림에 테두리를 그리지 않아도 됩니다.
- 등급이 높을수록 화려하게 그려 주세요. 모으는 재미의 절반이 여기에서 나옵니다.

## 캐릭터를 새로 추가하려면

1. `js/data.js`의 `CHARACTERS`에 한 줄을 더합니다.
   ```js
   { id: 'ellen', name: '엘렌', rarity: 'SR', cls: '마법사', tags: ['신성', '정찰'],
     bio: '소개 한두 줄.', secret: '★3에서 열리는 숨은 이야기.' },
   ```
   - `rarity`: N / R / SR / SSR, `cls`: 전사 기사 마법사 사제 궁수 도적 소환사 중 하나
   - `tags`: 특기 태그 1~2개 (`함정 어둠 신성 화염 정찰 방어 자연`). 던전이 요구하는 태그와 겹칠수록 성공률이 오릅니다.
2. 다른 캐릭터와 인연이 있으면 `BONDS`에 한 줄을 더합니다 (`'friend'` 또는 `'rival'`과 대사).
3. `assets/characters/ellen/card.png`, `icon.png`를 넣습니다.

도감은 검색, 등급·직업·보유 필터, 정렬을 모두 갖추고 있어서 수백 명까지 늘어도 쓸 수 있습니다.
