# 마계 진군 (가제) — 공성 시험장 M1

던전 운영 + 몬스터 부대 공성 게임의 공성전 코어. 계획은 [`docs/siege/`](../../docs/siege/README.md).

## 실행
```
npm install
npm run dev        # 브라우저에서 편성 → 공성전
npm run sim        # 편성별 승률·지휘 효과 이득 표 (빠르게: npm test)
npm run build      # 타입 검사 + 정적 빌드(dist/)
npx tsx tools/campaign.ts 3   # 캠페인을 처음부터 끝까지 자동 진행해 지역별 난이도 곡선 확인
```

## 구조
| 파일 | 내용 |
|---|---|
| `src/data/monsters.ts` | 몬스터 30종(5등급), 역할, 지휘 효과 |
| `src/data/castles.ts` | 성채(국경 요새): 3레인, 성문, 해자, 망루, 굴, 수비대 |
| `src/core/siege.ts` | 공성전 규칙 엔진(화면과 분리, Node에서 그대로 돎) |
| `src/render/view.ts` | Canvas, Asteria식 3/4 시점(왼쪽 → 오른쪽 진군) 화면과 연출 |
| `src/App.tsx` | Astryx 본부(지도·군단·시설·소환), 편성 화면, 전투 HUD, 결과와 보상 |
| `src/data/characters.ts` | 사람 모습 동료 13명의 대사, 측근 효과, 지역 적장 |
| `src/meta/campaign.ts` | 지역, 시설, 소환·굴복·타락, 저장(시간 개념 없음) |
| `tools/sim.ts` | 시뮬레이션: 편성마다 한계 수비 배율(지휘 효과 켬/끔) |

## M1에서 된 것
- 부대 = 부대장 + 병력(부대장 등급이 병력 수 결정), 부대장이 쓰러지면 지휘 효과가 꺼짐
- 3레인: 성벽(비행·성벽 진입만), 정문(해자·성문), 지하(굴착으로 열기, 성 안쪽 굴과 경사로)
- 망루는 성 밖만 쏨, 수비대는 자기 자리를 지킴, 성 안에서 레인이 합쳐짐
- 핵심 지점 8초 점거로 승리, 300초 제한, 별 평가, 부대 후퇴, 일시정지·배속
- 지휘 효과 15종 이상이 엔진에서 동작(속도, 첫 타, 성문 피해, 성벽 진입, 망루 빗맞힘, 부활, 회복, 공격력, 사거리, 굴 파기, 피해 감소 등)

## M2에서 된 것
- 부대 명령(전진/정지, 성문 공격/대기, 후퇴)
- 부대장 고유 스킬 12종 + 컷인과 스킬별 이펙트(숫자 키 1~3, 스페이스 일시정지)

## M3에서 된 것
- 성채 4곳(국경 요새, 바위 요새, 호수 성, 철문 성채)과 편성 화면의 성채 선택
- `npm run sim -- --castles`로 성채별 편성 한계 배율 표

## M4에서 된 것
- 본부(지도·군단·던전 시설·소환과 감옥), 지역 7곳 캠페인, 위협도, 보유 몬스터로만 편성, 보상·굴복·포로·타락, 브라우저 저장
- 대공 쇠뇌탑

## M5에서 된 것
- 적장 7명 포획·타락, 숙소와 호감도(대화·부대 능력), 측근, MVP 대사
- 몬스터 레벨(훈련)과 각성

## M6에서 된 것
- 계약 7종, 2장 지역 4곳(새 성채 산맥 신전·왕도 외성, 적장 루시아·엘렌·이리스), 캠페인 시뮬레이션으로 난이도 곡선

## 3장
- 결계 기둥, 새 성채 2곳(하늘 성채·왕성 내성), 지역 3곳, 적장 3명(세레나·아델·루나). 캠페인 14지역

그림은 아직 없고 도형으로 그린다(그림 규격은 `docs/siege/05_art_gpt.md`).
