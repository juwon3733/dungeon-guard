# 06. 기술과 개발 순서

## 기술 구성 (안)
| 부분 | 기술 | 이유 |
|---|---|---|
| 메뉴 화면(던전, 편성, 도감, 지도, 장부) | React 19 + Astryx | 표·목록·탭·툴팁이 많은 경영 화면에 맞음 |
| 공성전 화면 | Canvas 2D (필요하면 PixiJS) | 수십 마리 실시간, 이펙트 |
| 빌드 | Vite | Astryx(React) 사용 때문에 필요 |
| 규칙 | 순수 TS 모듈(화면과 분리) | Node에서 공성 시뮬레이션으로 밸런스 확인 |
| 데이터 | `src/data/*.ts` (몬스터, 성채, 지역, 시설) | 엔진은 데이터만 읽음 |
| 저장 | 브라우저 저장소(버전 번호 + 이전 규칙) | 나중에 서버 저장 추가 가능 |
| 배포 | GitHub Pages(정적) | 기존 방식 유지 |

정할 것: Astryx(React+빌드)로 갈지, 기존 프로젝트처럼 빌드 없는 순수 JS로 갈지. 메뉴가 많아서 Astryx 쪽을 권한다.

| M1 | 공성전 코어 | 부대(부대장+병력) 이동·자동 전투, 성벽·성문·망루, 핵심 점령, 지휘 효과 5종 | 성채 1개를 부대 3개로 공성, 시뮬레이션 승률 출력 |
| M2 | 공성 손맛 | 부대장 스킬 컷인, 이펙트, 성문 파괴·점령 연출, 일시정지 명령 | 플레이 영상 확인 |
| M3 | 몬스터 30종 | 1차 목록 데이터와 능력, 그림 연결(있는 것부터) | 30종 모두 공성에 넣어 시뮬레이션 |

| M6.5 | 캐릭터 시스템 | 적장 포획·타락, 숙소와 호감도, 측근, MVP 연출 | 1장 적장 2명을 사로잡아 타락시키고 호감도 10까지 |
| M7 | 메뉴 화면 정리 | Astryx로 편성·도감·장부·지도 | 모든 화면 조작 가능 |

| M9 | 다듬기 | 소리, 튜토리얼, 저장 안정성, 성능 | 외부 시험 플레이 |

M1과 M2가 재미의 핵심이라 가장 먼저, 가장 오래 다듬는다. 그림(M0)은 개발과 같이 진행한다.

## 시뮬레이션 기준 (M1부터)
- 성채마다 "권장 부대"로 자동 공성 승률 60~80%, 지휘 효과를 맞추면 90% 이상.
- 같은 전투력이라도 지휘 효과가 성채와 안 맞으면 40% 이하 → 판단이 의미 있는지 확인.
- 신화 하나로 모든 성채가 쉬워지지 않게(신화 1부대 + 일반 병력만으로 장 보스 승률 50% 이하).

## 진행 기록

### M1 공성전 코어 — 완료 (games/siege)
- 엔진·시뮬레이션·Astryx 편성 화면·Canvas 횡스크롤 화면.
- 시뮬레이션(`npm run sim`) 결과(국경 요새): 편성별 한계 수비 배율 0.8~1.35, 지휘 효과 이득 +4~17%.
  - 성벽 넘기가 가장 빠르고(약 76초, ★2.2), 지하 침투가 가장 단단하며(한계 1.35), 정문 힘싸움은 느리지만 안정.
  - 부대를 세 갈래로 나누면 각개 격파당해 약하다(한계 0.81).
- 발견: 오우거(성문 피해) 효과 이득이 0%. 성문을 일찍 부수면 망루가 살아 있는 채로 정문 수비대가 쏟아져 나와 정면전이 되기 때문.
  → "망루 먼저, 성문은 나중" 공략이 생김. M2에서 **성문 공격 대기/시작 명령**을 넣어 플레이어가 타이밍을 잡게 한다.

### M2 부대 명령과 부대장 스킬 — 완료
- 부대 명령: 전진/정지, 성문 공격/대기(정문 부대), 후퇴. 전투 화면 아래 부대 패널 버튼.
- 부대장 고유 스킬 12종(영웅 이상, `src/data/monsters.ts`의 `SKILLS`): 땅울림, 망자 일으키기, 매혹, 박쥐 떼, 돌진, 검은 방패, 저주 구름, 피의 연회, 썩은 숨결, 지옥불 투석, 노래, 종말의 불. 숫자 키 1~3, 스페이스는 일시정지.
- 스킬 연출은 화면을 덮는 띠 컷인이 아니라 **전장 안 카메라 연출**: 부대장에게 확대(영웅 1.6배·전설 1.8배·신화 2배) → 주변 어둡게, 부대장이 떠오르며 등급 색 기운이 모임, 스킬 이름은 머리 위에 작게 → 카메라가 빠지며 흔들림과 함께 이펙트가 터짐. 전설은 스킬마다 하늘색이 바뀌고, 신화는 하늘이 물들고 거대한 그림자가 지나간다. 연출 동안 전투는 멈춘다.
- 엔진에 기절, 받는 피해 증가, 부대 피해 감소, 예약 타격(타이머) 추가.
- 시뮬레이션(`npm run sim`)은 운영 방식 3가지(방치/스킬 자동/스킬+성문 대기)로 한계 배율을 비교한다.
  - 국경 요새: 스킬로 한계 배율 +4~31%. 리치(해골 소환)가 가장 크다(1.23 → 1.61) → 성채가 늘면 다시 맞춘다.
  - "망루가 무너질 때까지 성문 대기"는 정문 쪽에 사격 부대가 있을 때만 이득. 없으면 성 안쪽 망루를 못 부숴 손해(0.89 → 0.55였다).

### M3 성채 4곳 — 완료
- 새 성채 3곳(`src/data/castles.ts`), 편성 화면에서 성채 선택.
- 해마녀 지휘 효과를 "같은 레인의 모든 부대가 해자를 그대로 건넘"으로 넓힘. 리치 해골 소환 4기 → 2기, 재사용 26초.
- `npm run sim -- --castles`: 성채별 한계 배율(스킬 자동 + 성문 대기 명령). 기본 난이도(수비 배율)는 "맞는 공략은 이기고, 생각 없이 정면이면 지는" 선으로 정함.

| 성채 | 특징 | 기본 배율 | 통하는 공략(한계 배율) | 안 통하는 공략 |
|---|---|---|---|---|
| 국경 요새 | 입문, 세 길 모두 열림 | 1.3 | 해마녀 1.82, 비행 1.73, 오우거+방패 1.69 | 갈래 나누기 0.89, 망루 무력화 0.93 |
| 바위 요새 | 지하 없음, 망루 4 | 1.1 | 비행 1.48, 성벽 넘기 1.19 | 정면 0.85, 오우거 단독 0.76 |
| 호수 성 | 넓은 호수(느림 0.3), 지하 없음, 망루 3 | 1.1 | 비행 1.48, 해마녀 1.23 | 정면 0.89, 망루 무력화 0.55 |
| 철문 성채 | 성문 18000, 제한 210초, 짧은 굴 | 1.35 | 비행 1.61, 오우거+방패 1.57, 지하 1.57 | 오우거 단독 1.02, 갈래 나누기 0.81 |

- 발견: **성문 장사(오우거)는 혼자 가면 성문을 빨리 부수고도 전멸**한다(철문 성채 3/10승). 버티는 부대(타락 기사)와 같이 가면 성문 73초, 10/10승. 조합이 공략이 된다.

### 대공(M3 보충) — 완료
- 쇠뇌탑(비행 우선, 성 안까지 쏨, 비행 피해 2.5배)을 바위 요새·호수 성·철문 성채에. 성벽 궁수는 비행에 1.5배.
- 비행 군단이 모든 성채에서 1등이던 문제 해소. 성채 기본 배율 재조정.

### M4 진행(캠페인) — 완료 (`src/meta/campaign.ts`)
- 본부 화면 탭: 지도 · 군단 · 던전 시설 · 소환과 감옥. 진행은 브라우저 저장(`siege.meta.v1`).
- 지도: 지역 7곳을 차례로 연다(개척 마을 → 언덕 초소 → 강가 방앗간 → 국경 요새 → 철문 성채 → 호수 성 → 바위 요새). 점령할 때마다 위협도 +1, 아직 안 친 성채의 수비 강도 +0.04. 점령한 곳은 다시 공략해 보상 절반.
- 군단: 가진 몬스터로만 편성(가진 수를 넘으면 시작 불가). 시작 군단은 희귀 4(오크 전사·하피·해골 궁수대장·늑대 우두머리) + 일반 32.
- 시설 5종(시간 없음, 금화로 즉시): 둥지(수용량 50→70→100→140), 작전실(부대 2→3→4), 소환진(1~4단계 등급 확률), 광산(마석 +0/25/50%), 감옥(포로 2/4/6).
- 얻는 법: 소환(마석 50, 일반은 3마리), 굴복(이기면 그 지역 몬스터: 일반 확정 3마리, 희귀 60%, 영웅 25%), 타락(포로 + 마석 60 → 서큐버스·타락 기사·늪의 마녀 각 30%, 흡혈 군주 10%).
- 편성 화면은 기본 편성을 알아서 짠다: 근접 부대장 하나 + 사격 부대장 하나, 역할에 맞는 레인과 병력.
- 확인: 처음 상태에서 기본 편성으로 개척 마을 ★3 점령(81초) → 보상·굴복·포로 → 소환까지 브라우저로 한 바퀴.
- 남은 것: 지역 난이도 곡선은 첫 세 곳만 시작 군단으로 측정했다. 이후는 실제 플레이로 맞춘다. 훈련장(레벨), 대장간, 제단(각성), 계약은 아직 없음.

### M5 캐릭터 시스템과 성장 — 완료
- 적장 7명(`src/data/characters.ts`): 지역마다 수비대장이 이름을 달고 나온다. 이기면 사로잡음(★2 이상 확정, ★1이면 50%) → 감옥에서 타락 의식(마석 120) → 사람 모습 동료(영웅 4, 전설 3), 지휘 효과와 고유 스킬 있음.
  엘리제(개척 마을), 미라(언덕 초소), 실비아(강가 방앗간), 아리아(국경 요새), 베라(철문 성채), 셀레스(호수 성), 레이나(바위 요새).
- 숙소: 사람 모습 동료 13명(적장 7 + 서큐버스·늪의 마녀·타락 기사·흡혈 군주·해마녀·박쥐 여왕). 호감도 0~10, 함께 이기면 +1, MVP면 +2, 선물(금화). 2·5·10단계에서 대화가 열리고, 4·7·10단계에서 그 동료가 이끄는 부대 능력 +5/10/15%.
- 측근: 호감도 3 이상 1명. 본부 위에 대사와 함께 서 있고, 동료마다 보너스(금화·마석·굴복 확률·포로).
- MVP: 적에게 가장 많은 피해를 준 부대의 부대장이 결과 화면에 대사와 함께 나온다.
- 성장: 몬스터 종마다 레벨 1~20(금화로 훈련, 레벨당 +5%), 영웅 이상 각성 0~5(같은 몬스터 1 소모, 각성당 +8%).
- 확인: 처음 상태 → 개척 마을 ★3 → 엘리제 포획 → 타락 → 선물 3번 → 측근까지 브라우저로 한 바퀴.

### M6 계약·2장·캠페인 곡선 — 완료
- 계약 7종(`CONTRACTS`): 명성이 쌓이면 트롤 → 가고일 → 미노타우로스 → 리치 → 해골 용(소환진 3단계) → 마장군(1장 끝) → 심연의 용(소환진 4단계 + 장 보스). 마석을 내면 한 번씩 합류.
- 2장 지역 4곳: 산길 관문(철문형), 산맥 신전(새 성채, 기사 많음, 쇠뇌탑, 적장 성녀 루시아), 용사의 마을(적장 용사 엘렌, 신화), 왕도 외성(장 보스 새 성채: 성문 20000, 망루 5 중 쇠뇌탑 2, 굴 45, 수비대장 2, 적장 여왕 이리스, 신화).
- 적장 타락 비용은 등급별(영웅 150, 전설 300, 신화 600). 위협도 한 단계 +0.08.
- 캠페인 시뮬레이션 `npx tsx tools/campaign.ts [판 수]`: 가상의 플레이어(기본 편성, 스킬 자동 + 성문 대기, 시설 → 훈련, 적장 타락 → 계약 → 포로 타락 → 소환, 막히면 마지막 점령지 반복)가 처음부터 끝까지 진행한다.
  - 결과(3판): 11지역 모두 점령, 출격 43~89회. 앞 다섯 지역은 거의 한 번에(튜토리얼), 중반부터 막히며 키워서 넘어감. 가장 큰 고비는 왕도 외성.
  - 처음 측정 때 발견: 적장을 잡을 때마다 군단이 크게 강해져 11지역을 11번 만에 끝냈고(너무 쉬움), 호수형 성채는 땅 군단에게 벽이었다(30회 넘게 막힘). 지역 난이도·위협도·타락 비용으로 맞췄다.
