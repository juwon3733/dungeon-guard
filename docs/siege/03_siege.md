# 03. 공성전

## 부대
- 부대 = 부대장 1 + 병력 N (N은 부대장 등급: 희귀 4, 영웅 6, 전설 8, 신화 10).
- 병력에는 일반·희귀만. 같은 종을 여러 마리 넣을 수 있다(일반은 수량으로 보유).
- 한 공성전에 나가는 부대 수: 시작 2, 던전 시설(작전실)로 최대 4.
- 신화 부대장은 한 판에 1부대만.

## 성채 맵 (Asteria식 3/4 시점, 왼쪽 → 오른쪽 진군 + 3레인)
- **Asteria처럼 위에서 비스듬히 내려다보는 3/4 시점**이고(카메라 각도만 Asteria식. 성벽·망루·본관은 윗면과 앞면이 보이는 입체), 부대는 **왼쪽(아군 진영)에서 오른쪽(성)으로** 진군한다. 성벽은 세로로 길게 놓이고 가운데에 성문, 성 안은 넓은 안뜰, 오른쪽 끝에 **본관(핵심 지점)**. 화면은 가로 16:9, 맵은 화면 1.5~3배 너비로 좌우 스크롤한다.
- 전장은 위아래로 나란한 **3레인 띠**로 나뉜다(위=북쪽 성벽 구간, 가운데=정문 길, 아래=남쪽 굴). 부대마다 어느 레인으로 보낼지 고르는 것이 진입 지점 선택이다.

| 레인 | 위치 | 막는 것 | 들어가는 수단 |
|---|---|---|---|
| 위 (성벽) | 북쪽 성벽 구간 | 높은 성벽, 망루 | 비행, 사다리(대장간), 하피·박쥐 여왕 |
| 가운데 (정문) | 정문 길(해자는 여기만) | 해자, 성문, 수비대 | 공성 역할, 오우거 족장, 해마녀 |
| 아래 (지하) | 남쪽 굴(성벽 밑을 지나 안뜰 구멍으로) | 무너진 굴, 함정, 지하 수비대 | 굴착 고블린(굴을 열어야 다른 부대도 들어감) |

- 성채마다 레인 구성이 다르다. 지하 레인이 없는 성(바위 위의 요새), 위 레인에 망루가 몰린 성, 정문 앞 해자가 넓은 성 등.
- 레인은 성 안뜰에서 하나로 합쳐져 본관으로 이어진다. 먼저 뚫린 레인의 부대가 다른 레인의 수비대를 뒤에서 칠 수 있다.
- 부대는 이동 중에 **레인을 바꿀 수 있다**(사다리·굴 입구 같은 연결 지점에서만).
- 맵 구성 요소:
| 요소 | 내용 | 대응 |
|---|---|---|
| 성벽 | 지나갈 수 없음, 부수기 매우 오래 걸림 | 비행 진입, 굴착, 공성 역할 |
| 성문 | 부술 수 있음, 체력 큼 | 공성 역할, 오우거 족장 |
| 망루 | 원거리 공격, 범위 안 아군 지속 피해 | 버섯 주술사(명중 감소), 비행 기습 |
| 해자 | 건너는 동안 느려지고 공격받음 | 해마녀, 비행 |
| 수비대 | 성 안에서 순찰, 진입한 부대를 막음 | 전투 |
| 함정 | 숨겨진 피해 구역 | 정찰(박쥐) |
| 지하 통로 | 굴착 부대만 쓸 수 있는 진입로 | 굴착 고블린 |

- 부대는 띠 안에서 무리로 퍼져 움직이고, 부대장은 크게 + 등급 테두리, 비행 유닛은 그림자를 띄워 그린다. 부대장 스킬은 컷인으로 크게 보여 준다.

## 진행
1. **정찰**(공성 전): 성채 구성이 보인다. 함정·지하 통로는 정찰 시설 단계에 따라 보이는 정도가 다르다.
2. **편성**: 부대와 기본 레인을 정한다. 전장에는 모두 예비로 들어간다.
3. **실시간 전투**: 병력은 자동으로 싸운다. 플레이어가 하는 것
   - 부대 이동 명령(경로상의 목표 지점 바꾸기: 망루, 성문, 핵심 지점)
   - 부대장 고유 스킬 사용(영웅 이상, 재사용 시간)
   - 후퇴(부대를 빼서 피해를 줄임)
4. **종료**: 핵심 지점을 일정 시간 점거하면 승리. 모든 부대가 무너지거나 제한 시간(5분)을 넘기면 패배.

일시정지 상태에서도 명령을 내릴 수 있다(배속 ×1/×2, 일시정지).

## 연출
- 부대장 스킬은 컷인(부대장 일러스트 + 스킬 이름) → 이펙트 → 적중 순서.
- 성문 파괴, 망루 붕괴, 핵심 지점 점령은 카메라 흔들림·짧은 정지로 크게.
- 병력은 작은 스프라이트, 부대장은 크게 + 등급 테두리.

## 결과와 보상
- 점령: 점령 보상(금화·마석·재료) 한 번, 지역 영구 효과, 특산 몬스터 서식지(토벌) 열림.
- 전리품: 금화, 마석, 재료.
- 포로: 쓰러뜨린 인간 중 일부(성기사, 마법사 등) → 감옥 → 타락 의식(마석)으로 즉시 마족화.
- 굴복: 지역 야생 몬스터는 공성 뒤 "토벌"로 따로 잡는다(짧은 자동 전투).
- 실패: 전리품 없음, 잃는 것도 없음. 바로 다시 도전할 수 있다.

## 별 평가 (재도전 동기)
- ★1 점령, ★2 부대장 전원 생존, ★3 2분 안에 점령. 지역 ★ 합으로 장 보상.

## 들판(성 밖) — 외곽 방어선과 지형
성에 닿기 전 들판에도 성채마다 다른 장애물이 있다(`src/data/castles.ts`의 `outworks`, `terrain`, 투석기는 `towers`의 `splash`, 초소는 `garrison`의 `outpost`).

| 요소 | 효과 | 대응 |
|---|---|---|
| 목책 | 그 레인을 막는다. 부숴야 지나감(비행은 무시) | 공성·충차, 다른 레인으로 옮기기 |
| 가시밭 | 지나가는 동안 피해와 감속(비행 제외) | 비행, 돌아가기 |
| 투석기 | 멀리서 땅 위 모든 레인에 범위 피해, 부술 수 있음 | 빠르게 붙어서 부수기, 큰 방패 |
| 외곽 초소 | 성 밖 수비대. 다 쓰러뜨리면 그 레인 망루 피해 -30% | 먼저 정리할지 지나칠지 |
| 숲 | 숲 안 아군이 받는 원거리 피해 -30% | 숲 레인으로 접근 |
| 언덕 | 언덕 위 아군 사격 사거리 +25% | 사격 부대를 언덕에 세우기 |

## 전투 중 레인 바꾸기
- 부대 패널의 ↑/↓로 옆 레인으로 옮긴다. 성벽에 닿기 전이면 언제든, 옮기는 동안(한 칸 1초) 비스듬히 이동하며 공격하지 못한다. 굴이 없는 성은 지하로 못 간다.

## 예비대 투입 (지휘력)
- 전투가 시작되면 모든 부대가 예비다. 위쪽 지휘력 칸(최대 12, 시작 7, 약 1.8초에 1)이 차면 부대 패널의 성벽/정문/지하 버튼으로 원하는 레인에 내보낸다. 숫자키는 기본 레인으로 투입, 투입한 뒤에는 스킬.
- 투입 비용: 희귀 2, 영웅 3, 전설 5, 신화 7. 강한 부대일수록 오래 모아야 한다.
- 외곽 초소를 정리한 레인은 초소 자리에서 나온다(앞당겨진 투입 지점).
- 판단: 처음에 누구로 길을 열지, 성문이 깨지거나 굴이 뚫린 순간 어느 레인에 누구를 넣을지, 지휘력을 모아 신화를 넣을지 싸게 여러 번 넣을지.
- 시뮬레이션은 남은 부대를 다 낼 만큼 모았다가 기본 레인에 한꺼번에 넣는다(`autoDeploy`). 나뉘어 들어가는 만큼 지역 수비 세기에 0.93을 곱했다.
