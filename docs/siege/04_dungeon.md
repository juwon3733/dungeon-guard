# 04. 던전 운영과 지상 지도

## 자원
| 자원 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 금화 | 공성 전리품, 점령 보상 | 시설 건설, 레벨업 |
| 마석 | 공성 전리품, 점령 보상, 토벌 | 계약, 소환, 타락 의식 |
| 재료 | 전리품, 지역 특산 | 시설 강화, 각성 보조, 소환 재료 |
| 명성 | 공성 승리, 별 평가 | 계약 몬스터 방문 조건, 시설 해금 |

## 시간 없음
- 날짜, 턴, 출격 횟수 정산이 없다. 기다리는 것도 없다.
- 자원은 **공성과 토벌의 결과로 바로** 들어온다.
- 시설 건설, 소환, 계약, 타락은 비용을 내면 **즉시** 끝난다.
- 유지비와 피로도 없다. 대신 **군단 수용량**(둥지 단계)으로 보유 몬스터 수를 제한한다.
- 점령지는 점령할 때 보상을 한 번 주고, 이후로는 **영구 효과**(예: 짐승 굴복 확률 +, 소환 재료 할인)를 준다.

## 시설
던전은 칸 단위 굴. 굴을 파서 공간을 넓히고(금화) 방을 짓는다. 공간이 모자라 무엇을 먼저 지을지가 선택.

| 시설 | 효과 | 단계 |
|---|---|---|
| 둥지 | 군단 수용량(보유 몬스터 수 상한) | 1~5 |
| 훈련장 | 금화로 레벨업하는 비용 할인, 레벨 상한 | 1~5 |
| 광산 | 공성·토벌 때 얻는 마석 증가 | 1~5 |
| 보물고 | 금화 보관 상한, 이자 | 1~3 |
| 소환진 | 소환 등급, 재료 칸 | 1~5 |
| 감옥 | 포로 보관 수, 타락 의식 비용 할인 | 1~3 |
| 작전실 | 출전 부대 수(2→4), 정찰 수준 | 1~3 |
| 대장간 | 공성 장비(사다리, 충차) 제작 | 1~3 |
| 제단 | 각성, 계약 조건 해금 | 1~3 |
| 숙소 | 사람 모습 몬스터의 방, 대화·선물·호감도(07_characters.md) | 1~3 |

## 지상 지도
- 장(章) 단위 지역 묶음. 1장 국경 마을 지대 → 2장 숲과 요새 → 3장 강과 성채 도시 → 4장 신전 산맥 → 5장 왕도.
- 지역마다: 성채 맵 1개, 서식 몬스터, 점령 보상, 영구 효과(예: 숲 지역을 가지면 짐승 굴복 확률 +).
- 장 마지막 지역에 강적 성채(성기사단장, 대마법사, 용사).

## 위협도
- 우리는 **공격만 한다**. 방어전, 점령지 상실은 없다.
- 점령할 때마다 위협도가 오르고, 단계가 오르면 아직 안 친 성채들이 강해진다(수비대 증원, 망루 추가, 성기사 배치).
- 그래서 어느 지역부터 칠지가 전략이다. 쉬운 곳만 먼저 밀면 나중 성채가 더 단단해진다.
- 토벌 출격(야생 몬스터 사냥)은 위협도를 올리지 않는다.

## 첫 장(1장) 구성 예시
| 지역 | 성채 특징 | 공략 포인트 | 서식 몬스터 |
|---|---|---|---|
| 개척 마을 | 나무 울타리, 망루 1 | 튜토리얼, 정면 돌파 | 고블린, 거대 쥐 |
| 강가 방앗간 | 해자, 다리 하나 | 다리 정체를 피하는 우회 | 슬라임, 거대 거미 |
| 언덕 초소 | 망루 3, 좁은 길 | 망루 처리 순서 | 코볼트, 늑대 우두머리 |
| 국경 요새 (장 보스) | 돌 성벽, 성문, 수비대장 | 성문 공성 vs 비행 진입 | 가고일, 하피 |
