# 08. GPT 그림 전체 목록 — 코드 도형을 모두 그림으로

게임 화면에서 코드가 도형으로 그리는 것(동그라미 유닛, 글자 타일, 사각형 성벽, 원 나무, SVG 지도·아이콘)을 **전부** GPT 그림으로 바꾼다.
화면 틀(버튼·카드·메뉴 같은 UI 구조)은 Astryx 고딕 테마 그대로 두고, 그 안에 들어가는 **그림**만 GPT가 만든다.

## GPT에게 주는 규칙 (모든 묶음 공통)
- 저장소 `juwon3733/dungeon-guard`, 이 문서가 기준. 묶음 하나씩 맡는다.
- 결과는 `games/siege/public/assets/` 아래 **표에 적힌 경로·파일 이름 그대로** PNG로 넣고 `assets/<묶음id>` 브랜치로 올린다. 다른 파일은 건드리지 않는다.
- 첫 묶음 `style`에서 고른 그림을 `games/siege/public/assets/style/style_ref.png`로 두고, 이후 **모든 요청에 기준 그림으로 첨부**한다.
- 시트는 칸 크기가 모두 같고, 칸 사이 여백 없음, 배경 투명. 캐릭터는 칸마다 **발 위치가 같은 높이**(칸 아래에서 8%).
- 시점: 위에서 비스듬히 내려다보는 3/4 시점(Asteria 같은 각도). 아군은 **오른쪽**, 적은 **왼쪽**을 본다.
- 글자를 그림에 넣지 않는다(이름·숫자는 게임이 쓴다). 로고만 예외.
- 분위기: 마왕군이 인간 왕국을 공성한다. 어둡고 화려한 판타지, 모바일 수집형 게임 캐릭터. 의학·오타쿠 소재 없음.
- 사람 모습 여성 캐릭터는 몸에 맞는 옷, 적당한 노출까지(노골적인 것 없음).
