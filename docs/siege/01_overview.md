# 01. 개요

## 한 줄
작은 던전의 주인이 되어 던전을 키우고 몬스터를 모아, 부대를 꾸려 지상 왕국의 성채를 하나씩 공성해 점령하는 게임.

## 핵심 재미 세 가지
1. **부대 조합**: 부대장 1마리 + 병력 여러 마리. 부대장일 때만 켜지는 **지휘 효과**와 병력 구성이 맞물려야 강해진다. 같은 몬스터도 부대장이냐 병력이냐에 따라 쓰임이 달라진다.
2. **공성 판단**: 성채마다 성벽, 성문, 망루, 해자, 수비대 배치가 다르다. 어느 부대를 어느 지점에 어떤 순서로 넣을지가 공략이다. 같은 부대로도 성채에 따라 답이 바뀐다.
3. **모으고 키우는 맛**: 몬스터는 5등급. 침략한 지역의 몬스터를 굴복시키고, 떠돌이 몬스터와 계약하고, 소환진으로 부르고, 포로를 타락시켜 모은다. 높은 등급일수록 강하고 디자인도 공들인다.

## 큰 흐름
```
던전 운영 (시설, 자원, 육성)
   → 부대 편성 (부대장 + 병력)
   → 지상 지도에서 침략할 지역 고르기
   → 공성전 (실시간, 부대장 스킬과 부대 이동 지휘)
   → 점령 (지역 자원, 포로, 새 몬스터)
   → 위협도 상승, 용사단 반격
   → 다시 던전 운영
```

## 무게감
- 가볍고 짧은 스낵형이 아니라, 지도 전체를 몇십 시간에 걸쳐 점령해 가는 진득한 진행.
- 분위기는 적당히 어두운 판타지. 과하게 무겁거나 우스꽝스럽지 않게.
- 로그라이크 아님. 진행은 계속 쌓인다(지도, 몬스터, 시설).

## 다른 게임과 다른 점
| | 일반 수집형 RPG | 일반 공성 RTS | 마계 진군 |
|---|---|---|---|
| 전투 단위 | 캐릭터 4~6 | 병사 수백 | 부대 2~4개(부대장 + 병력) |
| 캐릭터의 역할 | 파티원 | 거의 없음 | 부대장일 때 지휘 효과, 병력일 때 전투 능력 |
| 맵 | 스테이지 | 전장 | 성채마다 공략 지점이 다른 공성 맵 |
| 성장 | 레벨 | 테크 | 던전 시설 + 몬스터 등급·레벨 + 점령지 |

## 플랫폼
- 웹(PC 우선, 가로 16:9). 태블릿은 그대로, 폰은 가로로.
- 나중에 데스크톱 앱으로 감쌀 수 있게 한다.

## 소재 원칙
- 오타쿠 문화, 의학/의대생 티는 넣지 않는다.
- 사람 모습의 몬스터(마족 등)는 예쁘고 멋있게, 노골적인 표현은 없다.
