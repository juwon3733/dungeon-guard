# 몬스터 설계

타워 대신 몬스터를 설치해 용사를 막는다. 2026-11-06 사용자 결정 기준이며, 수치는 플레이 후 고칠 초안이다. 계획서의 시설 설계를 대체한다.

## 확정된 것

- **전투:** 모든 몬스터는 길 옆 칸(`BUILD_CELLS`)에만 놓는다. 길 칸에는 놓지 못한다. 근접 몬스터는 놓은 칸에서 가장 가까운 길 지점으로 걸어 나가 막고, 원거리 몬스터는 놓은 칸에서 공격한다.
- **획득:** 층 보상과 영구 수집을 함께 쓴다.
  - 판을 시작할 때 몇 종으로 시작한다.
  - 층을 깰 때마다 후보 3종 중 하나를 골라 이번 판의 덱에 넣는다.
  - 후보는 영구 해금된 몬스터 중에서 나온다. 해금은 판이 끝나도 남는다.

## 분류

**역할**

| 역할 | 하는 일 | 설치 위치 |
|---|---|---|
| 탱커 | 길을 막고 오래 버팀 | 길 옆, 길로 나감 |
| 근접 공격 | 막으면서 강하게 때림 | 길 옆, 길로 나감 |
| 원거리 단일 | 앞선 용사 하나 집중 | 길 옆 |
| 원거리 광역 | 무리 공격 | 길 옆 |
| 지원 | 감속, 회복, 버프 | 길 옆 |

**계열** (함께 놓으면 효과): 언데드, 오크, 악마, 야수, 정령

**등급**

| 등급 | 차이 | 층 보상 확률 초안 | 출시 목표 |
|---|---|---|---|
| 일반 | 기본 수치만 | 60% | 16종 |
| 희귀 | 능력 1개 | 28% | 12종 |
| 영웅 | 능력과 고유 효과 | 10% | 8종 |
| 전설 | 판도를 바꾸는 패턴, 필드에 1마리 | 2% | 4종 |

## 초안 규칙

- 근접 몬스터는 쓰러지면 일정 시간 뒤 놓은 칸에서 다시 나와 길로 걸어간다.
- 판매하면 일부를 돌려받는다.
- 3단계까지 강화하고, 3단계에서 두 갈래 중 하나를 고른다.
- 영구 해금 조건 초안: 처음 몇 종은 기본 제공, 나머지는 지역 클리어와 도전 과제로 연다.

## 데이터 구조

몬스터는 표에 한 줄을 추가하면 들어가게 만든다. 코드에 몬스터 이름별 분기를 두지 않는다. 능력은 재사용 가능한 능력 종류와 값으로 적는다.

```js
{ id: 'skeleton_archer', name: '스켈레톤 궁수', role: 'ranged', family: 'undead', grade: 'common',
  sprite: 'pl_mon_skeleton_archer', cost: 50, stats: { hp: 40, damage: 8, interval: 0.8, range: 3 },
  abilities: [], unlock: 'start' }
```

수치 초기값은 역할과 등급별 공식으로 낸다. 몬스터마다 밸런스를 맞추지 않는다.

## 만드는 순서

1. **전환:** 시설을 몬스터로 바꾼다. 오크(탱커), 스켈레톤 궁수(원거리 단일), 암흑 마법사(원거리 광역). 하단 `타워` 탭을 `몬스터`로 바꾼다.
2. **데이터 틀:** 위 구조로 옮기고 등급 표시를 넣는다.
3. **층 보상:** 후보 3종 고르기와 이번 판 덱. 지금은 1개 층뿐이라 웨이브 묶음이나 층 구조가 먼저 필요하다.
4. **12종 시험:** 역할과 계열을 섞어 재미를 확인한다.
5. **영구 수집:** 저장, 해금 조건, 도감.
6. **계열 조합과 등급 연출.**
7. **40종 확장.**
