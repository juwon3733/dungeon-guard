# 아트 바이블

게임 그림 규격(도트 1칸 = 화면 2픽셀, 칸 64px)은 `docs/PIXELLAB_ASSETS.md`. 이 문서는 맵 지역, UI 재질, 색 역할, 전투 연출을 적는다. UI 값은 모두 `js/ui/uikit.js`, 지역 값은 `js/data/map.js`의 `ZONES`에 있다.

## 방향: Asteria 구성 (2026-11-07, 사용자 결정)

이전 재질(마왕군 작전 테이블: 양피지, 나무판, 쇠, 붉은 밀랍)은 "너무 유치하고 퀄리티도 낮다"는 평가로 버렸다. 사용자가 "Asteria 정도 느낌, Asteria 티 나도 돼"라고 정했다. Asteria는 사용자가 직접 만든 게임이고 그 그림(지역 섬, 배경, 다리, UI 틀)을 다시 쓴다. 기준 화면은 Asteria 스토어 스크린샷 `ko_02_abyss_combat`(하단 바, 전투 밀도), `ko_06_blacksmith`(창, 칸, 상세 창), `ko_08_field`, `ko_05_abyss_raid_party`.

## 맵: 떠 있는 섬

- 우주 배경(`void_<지역>.webp`) 위에 섬(`island_<지역>.webp`)을 띄운다. 섬 윗면이 전장(0~12줄)을 덮고 절벽은 13~14줄과 하단 바 뒤로 이어진다(`ISLAND_RECT`, 지역마다 `island`로 바꿀 수 있다).
- 길은 지역 다리 그림(`bridgedeck_<지역>.webp`)의 난간과 돌바닥을 잘라(`ZONES[].deck`, 아래 매달린 장식은 자른다) 경로를 따라 깐다. 폭은 칸보다 조금 넓다(`DECK_W` 132 = 화면 88px). 꺾이는 곳과 합류점(T자)은 길이 이어지는 쪽 난간을 지우고 같은 배율의 돌바닥으로 잇고, 네 귀퉁이에 지역 색 기둥을 세운다.
- 왕좌 둘레(3x4칸)는 지역 다리 돌바닥 받침에 금선과 기둥.
- 입구 문은 코드로 그린 소용돌이 문: 지역 색 돌 테두리 타원 안에서 도트 나선이 돌고, 빛과 빨려 드는 반짝이, 바닥에 pixelfx 룬 고리(`fx_rune_attackSpeed`).
- 섬 그림에 장식이 있어 소품은 지역마다 2~3개만(`ZONES[].props`), 분위기에 맞는 것만 고른다. 소품은 `PROP_CELLS`(건설 칸에서 빼 둔 칸)나 건설 칸 밖에만 놓아 지역이 바뀌어도 건설 칸은 같다.
- 빛은 섬 가운데를 지역 색으로 살짝 밝힌다(`light`). 비네트는 가장자리에 지역 색을 얹을 뿐 검게 덮지 않는다(`vignette`, 세기 0.2 이하). 맵 위에 상시 어둡게 덮는 효과는 쓰지 않는다(번개 주문 때의 어둠만 예외).

| `frost` | 서리 봉우리 | 스테이지 3 | 수정 |
| `skySea` | 하늘 바다 | 스테이지 4 | 수정, 바위 |
| `sunForge` | 태양의 대장간 | 스테이지 5 | 화로, 가마솥 |
| `warTemple` | 전쟁 신전 | 스테이지 6 | 깃발, 오벨리스크, 화로 |
| `starChoir` | 별의 성가대 | (아직 없음) | 오벨리스크, 수정 |

## UI 재질: 남색, 금선, 은청색

| 재질 | 쓰는 곳 | 그림 |
|---|---|---|
| 남색 창 | 창, 팝업, 카드, 파티 목록, 대화창 | `ui_window.png` 9칸(깊은 남색 판, 가는 금선, 네 모서리 금장). 가운데는 평평한 남색 |
| 금테 상세 창 | 도감·진열장·무기고 오른쪽 상세, 이번 판 효과 | 코드(`UI.drawDetailFrame`): 남색 판에 굵은 금선 |
| 작은 창 | 설명, 안내, 알림, 말풍선, 입구 인원 표 | 코드(`UIKit.note`): 남색 판에 가는 금테, 계단 모서리. 보스와 위험은 빨강 |
| 육각 이름판 | 위쪽 이름판, 대화 제목과 이름표, 본부 이름, 화면 제목 | 코드(`UI.drawHexPlate`): 양끝이 뾰족한 남색 판, 금선, 끝의 금 마름모 |
| 칸 | 보관함, 유물, 스킬, 소환, 도감과 진열장 칸 | `ui_itemSlot.png`(은테), `ui_skillSlot.png`(금테: 소환, 준비된 스킬, 고른 유물, 정예) |
| 띠 | 하단 바, 보스 등장과 히든 조합 띠 | 코드(`UIKit.plank`): 남색에 위아래 금선 |

- 9칸 그림은 정수 배율(기본 2배)로 그린다. 창과 칸의 변은 반복하고, 버튼은 위아래 음영이 줄무늬로 되풀이되지 않게 늘린다(`stretch`). 잘라 쓸 좌표는 `UI_SLICES`.
- 누른 버튼은 2px 내려앉는다. 마우스를 올리면 밝은 은청색(`ui_buttonHover`).
- 쓰지 않는 것: 양피지, 나무판, 쇠사슬 표지판, 붉은 밀랍 도장, 기울인 카드.

## 버튼

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 주요(`primary`) | 금색 입체(`UIKit.bevel`, `UI_BEVEL.gold`) | **화면에서 가장 중요한 행동 하나**: 웨이브 시작, 시작, 출전, 다음 스테이지·다시 도전, 해금 확인, 보상 고르기(마우스를 올린 카드만) |
| 보통(`silver`) | 은청색 입체(`ui_button.png`) | 도감, 닫기, 지도로, 오른쪽 위 금속 아이콘 버튼, 쪽 넘김 |
| 켜진 탭(`tab`) | 밝은 은청색에 금테, 흰 굵은 글자 | 하단 바 몬스터·마왕 탭, 도감 탭, 켜진 설정 |
| 꺼진 탭(`tabOff`) | 어두운 남색, 흐린 글자와 아이콘 | 켜지지 않은 탭 |
| 위험(`danger`) | 빨강 입체 | 판매, 기록 지우기 |
| 꺼짐(`off`) | 회청색 입체 | 누를 수 없는 버튼 |

소환은 버튼이 아니라 하단 금장 틀의 가장 큰 금테 칸이다. 칸 왼쪽 위에 단축키 표(`UI.drawKeyCap`)를 붙인다. 버튼과 탭에는 `uiicon_<summon|lord|attack|gold|soul|lock|book|bag|close|fast|pause|sound|gear|wave|retry|bolt>`을 48px 또는 96px로 넣는다.

## 화면 구성 (전투)

- 하단 바: 왼쪽 **체력 구슬**(금 고리 안 붉은 물이 마왕 체력만큼 차고 가운데 큰 숫자, 레벨 표지 없음), 그 옆 마왕 이름과 처치 수, 가운데 바 위로 솟은 **금장 틀**에 슬롯 줄(몬스터·마왕 탭, 소환 칸과 맵 몬스터 수 또는 번개·호통 칸과 유물 칸, 보관함), 오른쪽 골드(큰 숫자)와 다음 소환 값. 준비 시간에는 바 위 오른쪽에 금색 다음 웨이브 버튼, 웨이브 중에는 그 자리에 단축키 줄.
- 위쪽 가운데 육각 이름판: 지역 이름, 스테이지, 웨이브. 바로 아래 보스 체력(빨간 띠).
- 오른쪽 위: 다음 파티 남색 창 목록(종류마다 얼굴, 이름, 수. 정예는 금색, 보스는 빨강)과 금속 아이콘 버튼.
- 연속 처치: 체력 구슬 오른쪽 위 금테 알약에 큰 숫자.

## 카드와 목록 (Asteria 대장간처럼)

- 도감, 보물 진열장, 무기고: 왼쪽에 등급별 밝은 색 테두리 칸(그림, 이름, 오른쪽 아래 작은 등급 이름), 오른쪽에 금테 상세 창(마우스를 올린 것, 없으면 첫 항목). 못 얻은 것은 진한 남색 실루엣과 ???, 풀리는 스테이지 메달.
- 보스 보상: 반듯한 남색 카드 3장(기울이지 않는다), 등급 색 테두리, 왼쪽 위 단축키, 오른쪽 위 등급 이름.
- 선택 화면: 남색 마왕 카드(고른 카드는 금테), 은테 유물 칸(고른 것은 금테), 금테 상세 창(이번 판 효과).
- 스토리 지도: 남색 창에 점선 길(깬 구간 금색)과 메달(깸: 금 고리 붉은 보석, 다음: 밝은 은청색에 숨쉬는 금 고리, 잠김: 어두운 원과 자물쇠), 메달 아래 스테이지 이름과 지역 이름.
- 대화: 맵을 얇게 가라앉히고(`dimLight`), 위에 육각 제목판, 아래 남색 대화창에 금테 초상과 육각 이름표.
- 본부: 방의 나무 바닥, 카펫, 벽은 본부 그림 그대로 두고 이름표·말풍선·이름판만 남색과 금선으로 바꿨다.

## 색 역할 (`UI_THEME`)

바탕은 모두 남색이라 글자는 밝은 색이다. 역할 이름은 이전 재질의 이름을 그대로 쓴다.

| 역할 | 색 |
|---|---|
| 본문 / 보조 / 흐림 | `ink` #eef2ff / `inkSoft` #a9b5d6 / `inkFaint` #6b7799 |
| 좋음 / 나쁨 / 강조 | `inkGood` #7cf07a / `inkBad` #ff7a6a / `inkWax` #ffd35a |
| 큰 글자 / 보조 | `cream` #ffffff / `creamSoft` #c3cce6, 외곽선 `outline` #060a16 |
| 골드 / 좋음 / 나쁨 / 영혼석 | `gold` #ffd34d / `good` #8ef08a / `bad` #ff8a78 / `soul` #d9b8ff |
| 판 | `navy` #0e1730, `navyLight` #1b2a4e, `navyDark` #070d1d |
| 금선 | `goldLine` #e2ad45, `goldLight` #ffe08a, `goldDark` #7a5414 |
| 위험 | `wax` #c8323c(빨강), `waxLight`, `waxDark` |

- 창을 띄울 때 뒤를 가라앉히는 `dim`, `dimLight`는 남색이다. 맵 위 상시 효과로는 쓰지 않는다.
- 능력 이름은 `ABILITY_INK` #e8a6ff.

## 등급

굵고 밝은 등급 테두리(`UIKit.gradeFrame`, 3~6px). 일반 회백, 희귀 파랑, 영웅 보라, 전설 금색. 테두리는 `MONSTER_GRADES[].color`, 큰 글자는 `.light`, 창 위 글자는 `.ink`(밝은 색). 장비는 `EQUIPMENT[].grade`로 같은 색을 쓴다.

## 글

- 굵고 외곽선 있는 큰 숫자(`UIKit.bigText`: 두꺼운 외곽선, 아래 그림자, 위쪽 반을 밝게). 체력, 골드, 처치, 맵 몬스터 수, 제목에 쓴다.
- 안내는 남색 작은 창 한 줄로 짧게, 종류마다 처음 3번(`HINT_SHOWS`). 단축키는 일시정지 창과 웨이브 중 바 위 한 줄.
- 코믹한 대사와 말투는 살린다. 마왕 대사는 남색 말풍선, 보스 대사는 빨간 말풍선.

## 전투 연출 (Asteria 전투처럼 화려하게)

- 피해 숫자: 굵은 외곽선 글자(일반 34, 큰 피해 60, 세계 배율 보정), 처음 0.15초에 1.8배로 튀어나와 옆으로 조금 튀며 떠오른다.
- 처치: 흰 불꽃, 주황 파편, 금 파편, 퍼지는 고리, `fx_explosion`(정예와 보스는 `fx_blastGold`도), 빛, 떠오르는 `+골드` 글자, 돌며 HUD로 날아가는 금화(최대 9개). 일반 처치도 화면이 살짝 흔들린다(정예는 더).
- 연속 처치 3 이상: 처치 자리에 "N 연속!" 큰 글자(5의 배수는 더 크게, 10 이상은 붉게).
- 소환과 합치기: 등급별 연출(`GRADE_FX`)을 키웠다. 희귀 이상은 금빛 터짐과 빛기둥, 빛줄기, 흰 고리, 불꽃, 등급 색 빛. 결과 이름은 큰 외곽선 글자(전설 64). 히든 조합 발견 띠는 더 크고 반짝이가 쏟아진다.
- 랭크 업: 랭크 색 고리 둘, `fx_blastCyan`(S는 `fx_blastGold`), 빛, 흔들림, "랭크 X!" 큰 글자.
- FPS: 캡처 장면 모두 60 이상(측정 약 150~165).
