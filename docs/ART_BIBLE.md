# 아트 바이블

게임 그림 규격(도트 1칸 = 화면 2픽셀, 칸 64px)은 `docs/PIXELLAB_ASSETS.md`. 이 문서는 UI 재질과 색 역할을 적는다. 값은 모두 `js/ui/uikit.js`에 있다.

## UI 콘셉트: 마왕군 작전 테이블

코믹한 마왕이 전쟁을 지휘하는 나무 테이블. 밝고 따뜻하다. 재질은 네 가지뿐이다.

| 재질 | 쓰는 곳 | 그림 |
|---|---|---|
| 양피지 | 창, 팝업, 카드, 쪽지(안내, 알림, 설명, 말풍선), 켜진 탭 | `ui_kit.png` 양피지 창 9칸(`UI_SLICES.parchment`, 팝업은 쇠 테 `parchmentIron`), 작은 쪽지는 같은 양피지 무늬에 진한 갈색 테(`UIKit.note`) |
| 호두나무 판 | 하단 바, 위 표지판, 선택 화면과 도감 바탕, 보스 등장 띠, 보통 버튼 | `ui_buttons.png` 쇠 못 박힌 판(`woodBar`), 나무 버튼(`wood`) |
| 쇠 | 칸(보관함, 유물, 스킬), 쇠사슬, 못, 위험 버튼 테 | `ui_kit.png` 쇠테 칸(`slot`, `slotLight`, 고른 것은 `slotGold`) |
| 붉은 밀랍 | 주요 행동 버튼, 초상 액자, 도장, 보스 쪽지 | `ui_buttons.png` 옻칠 버튼(`lacquer`), 코드로 그린 밀랍 테(`UIKit.waxFrame`) |

- 9칸 창은 정수 배율(기본 2배, 모서리가 안 들어가면 1배)로 그린다. 모서리는 배율 그대로, 변과 가운데는 반복한다. 잘라 쓸 좌표는 `UI_SLICES` 표에 있다.
- 그라디언트로 입체를 내지 않는다. 밝기 차이는 도트 재질과 상태 덧칠(`UI_TINTS`: 마우스 올림, 꺼짐, 위험)로만 낸다.
- 누른 버튼은 2px 내려앉는다.
- 쓰지 않는 것: 어두운 남색·보라색 창, 금색 장식 창, 금색 그라디언트 버튼, 둥근 체력 구슬, 글자만 있는 버튼.

## 버튼

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 주요 | 붉은 옻칠 | 화면마다 하나: 소환, 웨이브 시작, 시작, 다시 도전, 보상 고르기(마우스를 올린 카드만) |
| 보통 | 나무판 | 탭(꺼짐), 도감, 닫기, 해금, 오른쪽 위 아이콘 |
| 켜짐 | 양피지 쪽지(못) | 켜진 탭, 조준 중인 번개, 켜진 설정 |
| 위험 | 진한 빨강 옻칠 + 쇠테 | 판매, 기록 지우기 |
| 꺼짐 | 빛바랜 회갈색 나무 | 돈이 모자란 소환, 넘길 쪽이 없는 화살표 |

주요 버튼과 탭, 재화, 잠금에는 `uiicon_<summon|lord|attack|gold|soul|lock|book|bag|close|fast|pause|sound|gear|wave|retry|bolt>`을 48px(1배) 또는 96px(2배)로 넣는다.

## 색 역할 (`UI_THEME`)

| 바탕 | 글자 | 색 |
|---|---|---|
| 양피지 | 본문 / 보조 / 흐림 | `ink` #3a2414 / `inkSoft` #6b4a2e / `inkFaint` #8f7354 |
| 양피지 | 좋음 / 나쁨 / 강조(제목 숫자, 비용) | `inkGood` #2f6b1f / `inkBad` #a3221e / `inkWax` #8f1d1d |
| 나무, 지도, 밀랍 | 본문 / 보조 | `cream` #fff1d6 / `creamSoft` #e8d3ad, 진한 갈색 외곽선 `outline` #1e120a |
| 나무, 지도 | 골드 / 좋음 / 나쁨 / 영혼석 | `gold` #ffd25a / `good` #a8e68a / `bad` #ff9a84 / `soul` #d9b8ff |

- 양피지 위에는 밝은 글자를 쓰지 않는다. 외곽선 글자(`UIKit.text`)는 나무와 지도 위에만, 양피지 위는 `UIKit.ink`.
- 화면을 덮는 어둠은 따뜻한 갈색(`dim`, `dimLight`)이다.

## 등급

굵고 밝은 등급 테두리(`UIKit.gradeFrame`, 4~6px)로 보인다. 일반 회백, 희귀 파랑, 영웅 보라, 전설 금색. 색은 `MONSTER_GRADES[].color`, 양피지 위 등급 글자는 `.ink`, 나무·지도 위는 `.light`. 보상 카드, 선택 화면, 도감, 팝업, 보관함, 합치기 미리보기, 맵 발밑 마름모(진한 갈색 테두리)에 같은 규칙을 쓴다. 장비는 `EQUIPMENT[].grade`로 같은 색을 쓴다.

## 글

- 제목과 숫자는 크게, 설명은 작게. 카드와 팝업은 아이콘과 숫자를 먼저 보여 준다.
- 화면 가운데 안내는 양피지 쪽지 한 줄로 짧게, 종류마다 처음 3번만(`HINT_SHOWS`). 단축키는 일시정지 창에 있다.
- 코믹한 대사와 말투는 살린다. 마왕 대사는 양피지 쪽지, 보스 대사는 붉은 밀랍 쪽지.
- 장면마다 같은 사각 카드를 반복하지 않는다: 선택 화면 마왕은 끈에 걸린 포스터, 보상은 살짝 기울어진 양피지 3장, 도감 몬스터는 못으로 꽂은 쪽지, 조합식은 나무 판 줄, 다음 파티는 밀랍 도장 찍힌 수배서.
