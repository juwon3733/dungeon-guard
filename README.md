# 던전 수호대 품질 시험판

계획서 1단계 시험판입니다. `index.html`을 더블클릭하면 설치 없이 실행됩니다.

- 범위: 지하 감옥 1개 층, 웨이브 10개, 몬스터 6종(일반 3, 희귀 2, 영웅 1)의 소환과 합치기, 용사 3종과 층 보스, 마왕 3명과 유물 16종, 마왕 스킬 2개, 파티 예고
- 시작: 타이틀에서 시작하면 선택 화면에서 마왕 1명과 유물(유물 칸 수만큼, 안 골라도 됨)을 고르고 시작 버튼(Enter)을 누릅니다. 유물은 눌러 넣고 다시 누르면 빼며, 마우스를 올리거나 누르면 효과가 보입니다. 다시 시작하면 선택 화면으로 돌아가고 직전 선택이 남아 있습니다(브라우저 저장소에 남기고, 못 읽으면 기본 선택). 판 중에는 유물을 얻지 않고, 마왕 탭에 고른 유물이 보입니다. 마왕은 균열의 군주(번개 피해 +25%, 스킬 재사용 ×0.9), 뼈의 여왕(부활 시간 ×0.6, 처치 경험치 +25%, 최대 체력 -3), 황금 마왕(시작 골드 +100, 처치 골드 ×1.2, 최대 체력 -5)이고, 스킬은 셋 다 번개와 호통입니다. 표와 수치 초안은 `js/data/demonlords.js`의 `DEMON_LORDS`, `RELICS`, `META_RULES`
- 영구 수집: 판이 끝나면 몬스터는 사라지고 영혼석(막은 웨이브 × 2, 승리하면 +15)이 남습니다. 처음에는 균열의 군주와 유물 4개(황금 주머니, 피의 성배, 악마 뿔, 갇힌 심장), 유물 칸 1개만 쓸 수 있고, 선택 화면에서 잠긴 마왕(각 20)과 유물(8 또는 14)을 누른 뒤 해금 버튼으로 삽니다. 유물 칸은 잠긴 칸 자리의 버튼으로 늘립니다(2번째 30, 3번째 80, 최대 3칸). 타이틀과 선택 화면의 도감에서 본 몬스터(못 본 것은 실루엣), 조합식(히든은 찾기 전 `???`), 판 수·승리 수·최고 웨이브·영혼석을 봅니다. 기록은 브라우저 저장소(`dungeonGuard.meta`)에 남고, 못 읽으면 처음 상태로 돕니다. 도감 기록 탭의 기록 지우기는 두 번 눌러야 합니다. 저장은 `js/game/meta.js`
- 조작: 하단 몬스터 탭의 소환(S)을 누르면 무작위 몬스터 1마리가 맵의 빈 길 옆 칸에 바로 나옵니다(일반 70%, 희귀 25%, 영웅 5%). 비용은 25G에서 시작해 소환할 때마다 1G씩 올라 60G에서 멈추고, 다시 시작하면 처음으로 돌아갑니다. 맵에는 24마리까지 두며(하단에 `현재 수/24` 표시), 가득 차면 합쳐서 자리를 만듭니다. 나오는 칸은 길에 가까운 빈 칸 중 무작위이고, 원거리 몬스터는 사거리 안에 길이 있는 칸, 막는 몬스터는 다른 막는 몬스터와 길 지점이 겹치지 않는 칸을 먼저 고릅니다. 맵의 몬스터는 끌어 다른 칸으로 옮길 수 있습니다(비용 없음). 몬스터를 다른 몬스터 위에 놓으면 합칩니다: 조합식이면 정해진 몬스터, 같은 등급이면 상위 등급 무작위(영웅끼리는 불가). 숨은 조합식도 있습니다. 몬스터를 누르면 수치, 함께 합칠 수 있는 조합, 판매(일반 20G, 희귀 60G, 영웅 150G)가 나옵니다. 마우스와 터치 모두 됩니다. 마왕 탭의 Q 번개·W 호통, Tab 탭 전환, Space 다음 웨이브, F 배속, P 일시정지, M 소리, Esc·우클릭 취소
- 제물: 맵의 몬스터를 끌어 왕좌의 마왕 위에 놓으면 몬스터가 사라지고 마왕 체력이 회복되며(최대 20, 마왕과 유물에 따라 달라짐) 번개 재사용 대기가 줄어듭니다. 일반 체력 +1·번개 -2초, 희귀 +2·-5초, 영웅 +5·-10초, 전설 +10·-30초이고 랭크마다 25%씩 커집니다(S는 2배). 웨이브 중에도 됩니다. 환불은 없습니다
- 장비: 보스 보상의 장비 카드와 정예 용사 처치(25%)로 얻어 하단 보관함(6칸)에 모이고, 맵의 몬스터 위로 끌어 놓으면 끼웁니다(몬스터당 1칸, 끼고 있으면 맞바꿈, 웨이브 중에도). 합치면 등급이 높은 장비 1개가 이어지고, 나머지와 제물·판매한 몬스터의 장비는 보관함으로 돌아갑니다(가득 차면 30G). 16종 표와 수치는 `js/data/monsters.js`의 `EQUIPMENT`, `EQUIP_RULES`
- 규칙 시험: `node tools/simulate.js` (전략별 승률. 뽑기 이전처럼 몬스터를 골라 고정 가격에 사는 기준), `node tools/smoke.js` (클릭 흐름)
- 화면 캡처: `npm install` 후 `node tools/capture.js [장면 이름...]` → `captures/`에 PNG 저장, 평균 FPS 출력, 콘솔 오류·빠진 그림이 있으면 종료 코드 1 (Edge 또는 Chrome 필요). 장면: title, select, selectLocked, collection, resultSouls, lordQueen, prep, summon, drag, dragMerge, mergeSuck, merge, mergeEpic, hidden, sacrifice, popup, popupField, crowded, ranks, combat, units, elites, archmage, abilities, legend, equipment, bossReward, archmageIntro
- 그림: 용사와 몬스터는 PixelLab 그림, 정예·부대장·마왕은 Asteria 원본 에셋입니다. 몬스터 표, 소환 확률, 조합식은 `js/data/monsters.js`, 설계는 `docs/MONSTER_DESIGN.md`.
- 소리: Web Audio 합성음입니다. 3단계에서 음원으로 교체합니다.
