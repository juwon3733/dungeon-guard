# 던전 수호대 품질 시험판

계획서 1단계 시험판입니다. `index.html`을 더블클릭하면 설치 없이 실행됩니다.

- 범위: 본부, 메인 스토리 1부(6스테이지, 스테이지마다 다른 지역), 웨이브 표 10개, 몬스터 23종(일반 8, 희귀 7, 영웅 5, 조합으로만 나오는 전설 3)의 소환과 합치기, 몬스터 능력 14종, 용사 3종과 층 보스, 마왕 3명과 유물 16종, 마왕 스킬 2개, 파티 예고
- 맵: 30 x 15칸(칸 64px). 우주 위에 떠 있는 섬에 다리 길을 깔았습니다. 지역은 8곳(달빛 정원, 별모래 해안, 서리 봉우리, 하늘 바다, 태양의 대장간, 전쟁 신전, 별의 성가대, 잿불 균열)이고 스테이지 1~6이 차례로 앞 6곳, 스토리 없는 판은 잿불 균열입니다(표는 `js/data/map.js`의 `ZONES`, 스테이지의 `zone`). 지역이 바뀌어도 경로와 건설 칸은 같습니다. 왕좌는 (27,7), 건설 칸은 2~12줄의 길 옆 2칸까지입니다.
- 입구 둘(합류형): 북쪽 입구(0,3)와 남쪽 입구(0,11)의 길이 (10,8)에서 만나 왕좌까지 같이 갑니다. 남쪽 갈래가 2칸 짧습니다. 1~2번째 웨이브는 북쪽으로만, 3번째부터 북:남 7:3, 5번째부터 6:4, 8번째부터 5:5로 나뉘어 오고(표는 `js/data/balance.js`의 `WAVES[].entry`, 수치 초안), 보스는 북쪽 입구로 옵니다. 출발 간격은 입구마다 따로 세고 남쪽은 반 박자 늦게 출발합니다. 오른쪽 위 파티 창에 입구별 인원이, 준비 시간에는 각 입구 문 위에 올 인원이 보입니다. 두 갈래 사이 낀 칸 (9,9)는 양쪽 길에 닿습니다
- 시작: 타이틀의 시작하기(기록이 있으면 이어하기)를 누르면 본부(마왕의 방)가 나옵니다. 시설을 누르거나 숫자 키 1~6으로 들어갑니다: 1 작전 테이블(스토리 지도), 2 서재(도감), 3 보물 진열장(마왕과 유물 목록, 잠긴 것은 풀리는 스테이지), 4 무기고(장비 16종, 등급·효과·얻는 법, 얻은 적 없는 것은 그림자), 5 고블린 비서(기록 장부와 기록 지우기), 6 도전의 문(콘텐츠, 처음부터 들어갈 수 있고 지금은 준비 중 안내). 새로 볼 것이 있는 시설에는 붉은 느낌표가 붙고 들어가면 사라집니다. 고블린 비서가 말풍선으로 다음 할 일을 알려 줍니다. 안 화면은 닫기나 Esc로 본부로, 본부의 Esc는 타이틀입니다. 스테이지를 깨면 본부에 장식이 늘어납니다(2, 4, 6번). 표는 `js/ui/hq.js`의 `HQ_ROOM`, `HQ_FACILITIES`, `HQ_CONTENTS`
- 스토리: 작전 테이블의 지도에서 스테이지를 고르고 출전하면 시작 전 대화, 마왕과 유물 고르기(고를 것이 없으면 건너뜀), 전투, 승리 대화, 해금 카드, 결과 화면(다음 스테이지, 본부로) 순서입니다. 대화는 클릭이나 Space로 넘기고 Esc로 건너뜁니다. 지면 다시 도전(대화 없이 바로)이나 본부로 돌아갑니다. 고르기 화면에서 유물은 눌러 넣고 다시 누르면 빼며, 마우스를 올리거나 누르면 효과가 보입니다. 직전 선택은 브라우저 저장소에 남기고, 못 읽으면 기본 선택입니다. 판 중에는 유물을 얻지 않고, 마왕 탭에 고른 유물이 보입니다. 마왕은 균열의 군주(번개 피해 +25%, 스킬 재사용 ×0.9), 뼈의 여왕(부활 시간 ×0.6, 처치 경험치 +25%, 최대 체력 -3), 황금 마왕(시작 골드 +100, 처치 골드 ×1.2, 최대 체력 -5)이고, 스킬은 셋 다 번개와 호통입니다. 표와 수치 초안은 `js/data/demonlords.js`의 `DEMON_LORDS`, `RELICS`
- 메인 스토리와 해금: 메인 스토리는 튜토리얼처럼 6스테이지로 빠르게 끝나고, 게임의 중심은 본부의 도전의 문입니다. 스테이지를 처음 깰 때 마왕, 유물, 유물 칸이 풀립니다. 처음에는 균열의 군주만 있고 유물 칸은 0개입니다. 1번에서 유물 칸 1개, 3번에서 뼈의 여왕, 4번에서 유물 칸 2번째, 5번에서 황금 마왕, 6번에서 유물 칸 3번째와 엔딩. 다음 스테이지는 이전 스테이지를 깨면 열리고, 깬 스테이지는 다시 할 수 있습니다(해금은 처음 깰 때만). 스테이지는 웨이브 표(`WAVES`)를 인덱스로 골라 쓰고 용사 체력 배율(0.5~0.8)과 시작 골드 보너스가 있습니다. 표와 대사는 `js/data/story.js`의 `STAGES`(수치 초안). 기록(깬 스테이지, 본 몬스터, 조합식, 얻은 장비, 판 수)은 브라우저 저장소(`dungeonGuard.meta`, 버전 3)에 남고, 못 읽으면 처음 상태로 돕니다. 12스테이지 때(버전 2) 저장은 진행을 새 표로 옮기고(옛 번호 N → 새 번호 ceil(N/2)), 그 이전 버전은 몬스터와 조합식 기록, 판 수만 옮깁니다. 기록 지우기는 두 번 눌러야 합니다. 저장은 `js/game/meta.js`
- 조작: 하단 몬스터 탭의 소환(S)을 누르면 무작위 몬스터 1마리가 맵의 빈 길 옆 칸에 바로 나옵니다(일반 70%, 희귀 25%, 영웅 5%). 비용은 25G에서 시작해 소환할 때마다 1G씩 올라 60G에서 멈추고, 다시 시작하면 처음으로 돌아갑니다. 맵에는 24마리까지 두며(하단에 `현재 수/24` 표시), 가득 차면 합쳐서 자리를 만듭니다. 나오는 칸은 길에 가까운 빈 칸 중 무작위이고, 원거리 몬스터는 사거리 안에 길이 있는 칸, 막는 몬스터는 다른 막는 몬스터와 길 지점이 겹치지 않는 칸을 먼저 고릅니다. 맵의 몬스터는 끌어 다른 칸으로 옮길 수 있습니다(비용 없음). 몬스터를 다른 몬스터 위에 놓으면 합칩니다: 조합식이면 정해진 몬스터, 같은 등급이면 상위 등급 무작위(영웅끼리는 불가). 숨은 조합식도 있습니다(공개 11개, 히든 5개 중 3개는 재료 랭크 A 조건). 몬스터를 누르면 수치, 함께 합칠 수 있는 조합, 판매(일반 20G, 희귀 60G, 영웅 150G)가 나옵니다. 지원 몬스터(도깨비불 수련사, 오크 주술사, 대리치)는 고를 때만 오라 범위를 보여 줍니다. 마우스와 터치 모두 됩니다. 마왕 탭의 Q 번개·W 호통, Tab 탭 전환, Space 다음 웨이브, F 배속, P 일시정지, M 소리, Esc·우클릭 취소
- 제물: 맵의 몬스터를 끌어 왕좌의 마왕 위에 놓으면 몬스터가 사라지고 마왕 체력이 회복되며(최대 20, 마왕과 유물에 따라 달라짐) 번개 재사용 대기가 줄어듭니다. 일반 체력 +1·번개 -2초, 희귀 +2·-5초, 영웅 +5·-10초, 전설 +10·-30초이고 랭크마다 25%씩 커집니다(S는 2배). 웨이브 중에도 됩니다. 환불은 없습니다
- 장비: 보스 보상의 장비 카드와 정예 용사 처치(25%)로 얻어 하단 보관함(6칸)에 모이고, 맵의 몬스터 위로 끌어 놓으면 끼웁니다(몬스터당 1칸, 끼고 있으면 맞바꿈, 웨이브 중에도). 합치면 등급이 높은 장비 1개가 이어지고, 나머지와 제물·판매한 몬스터의 장비는 보관함으로 돌아갑니다(가득 차면 30G). 16종 표와 수치는 `js/data/monsters.js`의 `EQUIPMENT`, `EQUIP_RULES`
- 규칙 시험: `node tools/simulate.js` (전략별 승률. 스토리 없이 웨이브 표 10개 전부, 뽑기 이전처럼 몬스터를 골라 고정 가격에 사는 기준), `node tools/smoke.js` (클릭 흐름, 본부 시설, 저장 이전, 스토리 1~6번 끝까지 깨기 포함)
- 화면 캡처: `npm install` 후 `node tools/capture.js [장면 이름...]` → `captures/`에 PNG 저장, 평균 FPS 출력, 콘솔 오류·빠진 그림이 있으면 종료 코드 1 (Edge 또는 Chrome 필요). 장면: zones(지역 8곳을 차례로, `zones_<지역>.png`), title, select, selectLocked, collection, hq(본부), hqRelics(보물 진열장), hqArmory(무기고), storyMap(스토리 지도), dialogue(시작 전 대화), unlockCard(해금 카드), resultSouls(스테이지 승리 결과), lordQueen, prep, summon, drag, dragMerge, mergeSuck, merge, mergeEpic, hidden, sacrifice, popup, popupField, crowded, ranks, combat, units, elites, archmage, abilities, legend, equipment, bossReward, twoGates, merge2, archmageIntro, roster(23종을 모두 올린 맵), abilities2(확장 능력 효과), mapOverview(빈 맵 전체)
- 그림: 캐릭터, 마왕, 소품, 장비, 유물, UI 아이콘, 본부는 이 게임을 위해 PixelLab으로 만든 그림입니다(`docs/PIXELLAB_ASSETS.md`). 지역(섬, 우주 배경, 다리)과 UI 틀(창, 버튼, 칸)은 사용자가 만든 게임 Asteria의 그림을 다시 씁니다(사용자 결정, `NOTICE.md`). UI 재질과 화면 구성은 `docs/ART_BIBLE.md`. 도트 1칸은 화면 2픽셀입니다. 전투 효과는 모두 pixelfx 시트(`assets/fx/`, 만드는 법은 `tools/pfx_sheets.mjs`와 `docs/PIXELLAB_ASSETS.md`)입니다. 몬스터 표, 소환 확률, 조합식은 `js/data/monsters.js`, 설계는 `docs/MONSTER_DESIGN.md`.
- 소리: Web Audio 합성음입니다. 3단계에서 음원으로 교체합니다.
